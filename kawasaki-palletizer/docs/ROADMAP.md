# Roadmap

## Zrobione w 3.0

- podział na małe moduły (rdzeń, stan, interfejs),
- migrator starszych plików projektu,
- raport projektu do wydruku / PDF,
- kąt O przeliczany do układu BASE,
- podgląd 3D stosu,
- układy mieszane 0°/90° w generatorze.

## Najbliższe

1. Import punktów z kodu AS.
2. Import tabeli ze schowka / CSV.
3. Eksport PNG warstw.
4. Profile stanowisk Kawasaki.
5. Pełniejsza matematyka orientacji O/A/T.

## Później

- analiza podparcia produktów między warstwami,
- eksport dla innych robotów jako oddzielne wtyczki,
- wersja instalowana (PWA lub aplikacja desktopowa).
