# 00 - Skrzynka

Domyślne miejsce zapisu. Wszystko, co łapiesz w ciągu dnia, ląduje tutaj **bez**
decydowania o kategorii.

Zasada: opróżniasz do zera raz w tygodniu. Jeśli notatka leży tu dłużej niż dwa
tygodnie i nic z nią nie zrobiłeś - usuń ją. Nie była potrzebna.

W Obsidianie ustaw ten folder jako domyślną lokalizację nowych notatek:
*Settings → Files and links → Default location for new notes → in the folder specified below → `00-skrzynka`*.
