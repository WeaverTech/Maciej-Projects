# 50 - Notatki trwałe

Twoje własne wnioski, napisane własnymi słowami - jedna myśl na notatkę.

Różnica wobec `30-zasoby`: tam leży to, co powiedział ktoś inny; tutaj to, co z tego
wynika dla Ciebie. Notatka trwała powinna być zrozumiała bez źródła.

Tytuł zapisuj jako zdanie twierdzące, np. "Import CAD do Isaac Sim idzie przez USD
i gubi osie przegubów" zamiast "Isaac Sim - import".

Z czasem to jest najcenniejsza część systemu: stąd biorą się posty, README i odpowiedzi
na rozmowach technicznych.
