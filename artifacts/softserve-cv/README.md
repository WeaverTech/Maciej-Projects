- `Maciej_Tkacz_CV_SoftServe_EN_ATS.pdf` / `.docx` - recommended for the official application form and ATS parsing.
- `Maciej_Tkacz_CV_SoftServe_EN_Visual.pdf` / `.docx` - recommended for direct email or LinkedIn message to a recruiter.
- `Maciej_Tkacz_CV_SoftServe_PL_ATS.pdf` / `.docx` - Polish ATS version.
- `Maciej_Tkacz_CV_SoftServe_PL_Visual.pdf` / `.docx` - Polish visual/sidebar version.
